Web Server Deployment on AWS EC2 Using Nginx

Project Overview

This project demonstrates how to deploy a web server on an AWS EC2 instance using the Nginx web server.

Technologies Used

- AWS EC2
- Linux
- Nginx
- Git
- GitHub

Project Architecture

User → Internet → AWS Security Group → EC2 Instance → Nginx Web Server

Implementation Steps

1. Created an AWS EC2 instance.
2. Connected to the EC2 instance.
3. Configured the Linux environment.
4. Installed the Nginx web server.
5. Started and enabled the Nginx service.
6. Configured security group rules to allow HTTP traffic.
7. Accessed the web server using the EC2 public IP address.
8. Uploaded project files to GitHub.

Key Learnings

- AWS EC2 instance management.
- Linux command-line administration.
- Nginx installation and configuration.
- AWS Security Group configuration.
- Git and GitHub version control.
